Sequence Unrolling

See how a single RNN cell is reused across every timestep — the same weights process each input character sequentially while passing hidden state forward.

Key Concepts

  • Each RNN cell shares identical weights W, U, b
  • W (recurrent weight): multiplies the previous hidden state ht-1
  • U (input weight): multiplies the current input xt
  • b (bias): a learned offset added at each step
  • Hidden state ht flows left → right as a memory chain
  • At each step: ht = tanh(W·ht-1 + U·xt + b)

How to Use

  • Press Play to animate the sequence processing
  • Use the Step slider to jump to any timestep
  • Adjust Speed (0.5x, 1x, 2x)
  • The heatmap below shows hidden state values at each timestep — columns = timesteps, rows = hidden dimensions (d0…dn-1)

What to Observe

  • The active cell pulses and shows internal operations (Embed → tanh → Linear)
  • Hidden state preview mini-cells show activation patterns
  • The heatmap reveals which dimensions are most active at each timestep
  • Blue = negative, Orange = positive activations
